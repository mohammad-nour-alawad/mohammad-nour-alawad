## About me

I am an **AI researcher and Machine Learning Engineer at ITMO University**, where I work on **adaptive Human–AI collaboration through agentic systems**.

My research sits at the intersection of software engineering and modern AI systems, with a particular focus on how AI agents can better **understand developers, manage context and memory, explore large repositories, select models intelligently, and collaborate with humans more effectively**.

Alongside research, I build the systems needed to make these ideas work in practice: coding agents, evaluation infrastructure, LLM serving stacks, backend services, developer tools, data pipelines, and production-oriented AI platforms.

## What I work on

### Agentic software engineering

I study and build agents that operate over real software repositories: exploring codebases, localizing issues, reasoning over repository structure, assisting with repair, and evaluating how agent behavior changes under different context and resource constraints.

### Developer-personalized AI

I work on systems that learn from developer behavior and project history to make coding agents more context-aware, less repetitive, and better aligned with individual workflows.

### Adaptive LLM systems

I build and evaluate multi-model AI systems involving **model routing, context management, retrieval, memory, inference serving, and agent orchestration**, with an emphasis on choosing the right amount of model effort for each stage of a task.

### AI developer platforms

At ITMO, my work also includes designing and building developer-facing AI infrastructure: editor integrations, coding agents, backend APIs, model serving, Git/GitHub automation, sandboxed execution, analytics, evaluation pipelines, and deployment infrastructure.

*AgenticDev @ IEEE/ACM ASE 2026*

Repository-level agentic issue localization with an emphasis on reducing exploration cost while retaining strong localization performance.
