## Обо мне

Я исследователь в области **искусственного интеллекта** и инженер по машинному обучению в **Университете ИТМО**, где моя работа посвящена **адаптивному взаимодействию человека и ИИ с помощью агентных систем**.

Мои исследования находятся на пересечении программной инженерии и современных ИИ-систем. Меня особенно интересует, как ИИ-агенты могут лучше **понимать разработчиков, управлять контекстом и памятью, исследовать большие программные репозитории, выбирать подходящие модели и эффективнее взаимодействовать с человеком**.

Помимо исследовательской работы, я создаю практические системы, необходимые для реализации этих идей: coding agents, инфраструктуру оценки, стеки инференса LLM, backend-сервисы, инструменты для разработчиков, конвейеры обработки данных и AI-платформы, ориентированные на реальное использование.

## Чем я занимаюсь

### Агентные системы для программной инженерии

Я исследую и разрабатываю агентов, работающих с реальными программными репозиториями: они исследуют кодовую базу, локализуют проблемы, анализируют структуру репозитория, помогают при исправлении программного обеспечения и проходят оценку в условиях различных ограничений по контексту и ресурсам.

### Персонализированный ИИ для разработчиков

Я работаю над системами, которые используют поведение разработчика и историю проекта, чтобы сделать coding agents более контекстно-зависимыми, менее повторяющимися и лучше согласованными с индивидуальными рабочими процессами.

### Адаптивные LLM-системы

Я разрабатываю и оцениваю multi-model AI-системы, включающие **маршрутизацию моделей, управление контекстом, retrieval, память, инференс и оркестрацию агентов**, с акцентом на выбор подходящего уровня модельных и вычислительных ресурсов для каждого этапа задачи.

### AI-платформы для разработчиков

В ИТМО моя работа также включает проектирование и разработку инфраструктуры ИИ для разработчиков: интеграции с редакторами, coding agents, backend API, инференс моделей, автоматизацию Git/GitHub, sandboxed execution, аналитику, конвейеры оценки и инфраструктуру развёртывания.
